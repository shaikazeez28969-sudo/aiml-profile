# Project Ideas

This folder is intended for AI/ML and data science projects.

## Suggested structure

```text
projects/
├── sales_forecasting/
├── sentiment_analysis/
├── image_classification/
├── mlops_starter/
└── README.md
```

## Project recommendations

- Sales forecasting with time-series models
- Sentiment analysis using NLP
- Image classification with CNNs
- Recommendation engine basics
- Fraud detection or churn prediction
- Dashboarding with Streamlit or Dash

## Notes

Each project can include:
- dataset or source link
- data preprocessing notebook
- model training scripts
- evaluation metrics
- result summary
- deployment demo if applicable
